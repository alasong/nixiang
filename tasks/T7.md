# T7 多 Agent 并行样例：三个互不相同的写目标

三个子目标写不同文件，验收各带 `sleep 0.3`，用来对比串行与并行的墙钟差异；
写域不重叠，所以 `--agents 3` 可以真并行。

## 子目标

1. 在 /tmp/xm-t7-a.txt 写入 alpha
   验收：sleep 0.3 && grep -q alpha /tmp/xm-t7-a.txt
2. 在 /tmp/xm-t7-b.txt 写入 beta
   验收：sleep 0.3 && grep -q beta /tmp/xm-t7-b.txt
3. 在 /tmp/xm-t7-c.txt 写入 gamma
   验收：sleep 0.3 && grep -q gamma /tmp/xm-t7-c.txt
