# 开放任务测试：用 AI 怎么赚钱

**日期** 2026-11-18 ｜ **任务** 写一份决策备忘，比较数据项目、自动化项目、超级助手三条 AI 变现路线
**验收** `tasks/open-verify.py` 结构代理：三条路线关键词、≥3 个二级标题、≥500 字、≥3 个数字、含“结论”

> 结论：**当“报告生成器 + 评审选择器”能用；当“自主规划器”不行。**
> 验收是手写的结构代理，只查形式，不查观点对错；评审分未与人类对齐。

## 一、跑法

```bash
TASK='写一份决策备忘：用 AI 怎么赚钱——比较数据项目、自动化项目、超级助手三条路线…'
# 单候选
zsh -ic "python3 -m mvp.handle --task '$TASK' --out /tmp/ai-money-1.md \
  --verify 'python3 tasks/open-verify.py /tmp/ai-money-1.md' --candidates 1"
# 两候选 + 评审
zsh -ic "python3 -m mvp.handle --task '$TASK' --out /tmp/ai-money-2.md \
  --verify 'python3 tasks/open-verify.py /tmp/ai-money-2.md' --candidates 2 --judge"
# 符号反推 / 模型形式化
python3 -m mvp.handle --task "$TASK" --verify "python3 tasks/open-verify.py /tmp/x.md" --auto-plan
zsh -ic "python3 -m mvp.handle --task '$TASK' --out /tmp/ai-money-3.md \
  --verify 'python3 tasks/open-verify.py /tmp/ai-money-3.md' --formalize"
```

## 二、读数

| 跑法 | 结果 | 读数 |
|---|---|---|
| 单候选 | pass | 1252 字符；验收 `headings=3 chars=1251 digits=77 failed=[]` |
| 2 候选 + judge | pass | 选中第 2 份；`quality best=95 single=88`；1210 字符，4 个二级标题 |
| 符号反推 `--auto-plan` | 拒绝（设计如此） | “验收条件里没有可反推动作”；rc=2 |
| 模型形式化 `--formalize` | **fail** | 子目标 0/2；计划写到 `/workspace/ai-money-decision-memo.md`，不认 `--out`；目标文件不存在 |

## 三、怎么读

1. **开放任务能出活**：单候选报告已含三条路线的投入/回本/风险/适用条件与结论；两候选里评审给 95 vs 88，选中更高分那份——在开放任务上，评审分终于有区分度（简单任务上≈0）。
2. **但“更好”是评审的意见**：没有人类标注，95 vs 88 不能当质量事实；只能说明选择器在工作。
3. **验收是结构代理**：关键词/标题/长度/数字达标≠观点成立。要判观点，得有人类 rubric（T22）。
4. **自主规划失败**：形式化器（`formalize-ds-v1`）自己发明输出路径且忽略 `--out`，导致文件不存在；这是实现缺口，不是“AI 做不到”。
5. **符号反推边界正确**：`--auto-plan` 认出这是开放验收（非 grep/test -f/&&），明确拒绝而不是硬猜。
