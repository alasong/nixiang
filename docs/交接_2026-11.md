## 三、能做什么（入口）

```bash
# 任意任务 + 验收
python3 -m mvp.handle --task "在 /tmp/x.txt 写入 hello" --verify "grep -q hello /tmp/x.txt"

# 复合任务 / 并行 / 审计
python3 -m mvp.handle --task tasks/T7.md --verify "make docs-check" --agents 3 --audit

# 自由文本 → 计划（离线可复现 / 真实模型）
python3 -m mvp.handle --task "..." --verify "..." --formalize-from tasks/T12-plan.md --progress

# 从验收反推动作（符号逆向，不调模型；--width/--depth 控制搜索）
python3 -m mvp.handle --task "..." --verify "grep -q hello /tmp/x.txt" --auto-plan --explain-plan

# N 路候选 + 评审（离线 / 真实）
python3 -m mvp.handle --task "..." --out /tmp/x.txt --verify "..." \
  --candidates-from tasks/T8-candidates.jsonl --judge-from tasks/T10-judge.jsonl

# 失败反馈修复
python3 -m mvp.handle --task "..." --out /tmp/x.txt --verify "..." \
  --candidates-from tasks/T14-candidates.jsonl --repair-from tasks/T14-repair.jsonl --repair 1
```

真实模型需要 key；key 在 `~/.zshrc`，非交互 shell 拿不到，用 `zsh -ic` 跑。
